# Sojourn Brand System

Sojourn Korea 부산 프라이빗 투어 캠페인의 모든 산출물이 공유하는 브랜드 규칙이다. 이 파일이 유일한 진실 공급원이며, 각 제작 스킬은 여기서 정의한 토큰만 사용한다. 값을 각자 다시 정의하면 6장 카드가 서로 다른 브랜드처럼 보이므로, 새 값이 필요하면 이 파일을 고쳐라.

## 0. 사업 컨텍스트

| 항목 | 값 |
|------|-----|
| 브랜드 | Sojourn Korea (sojournkorea.net) |
| 본업 | 한국 이주·정착 서비스 — 비자, 주거, 은행, 병원 동행, 차량 |
| 이번 캠페인 대상 | **부산 프라이빗 투어** (랜딩: `/private-tour` — 아래 표 참조) |
| 투어 구성 | 전용 차량 + 맞춤 일정. 광안리·해운대·감천문화마을 중심. 시간제/일일 요금 |
| 콘텐츠 언어 | **영어 단독** — 사이트가 전면 영문이므로 랜딩 경험과 끊기면 안 된다 |
| 1차 타겟 | 부산 방문 외국인 개인/가족 여행객 |
| 2차 타겟 | 한국 주재원·유학생·은퇴 이주자 (가족 방문객 동반 투어 수요) |
| 3차 타겟 | 기업 HR·주재원 재배치 담당자 (LinkedIn 전용 앵글) |

### 랜딩 페이지 (2026-08-03 확인)

| 항목 | 값 |
|------|-----|
| **정식 URL** | `https://www.sojournkorea.net/private-tour` ← **이 주소를 그대로 쓴다** |
| H1 | Discover Busan & Seoul, privately. |
| 부산 코스 | Busan Highlights(전일) · Markets & Food(반일) · Coast & Culture(반일) |
| 등장 고유명사 | Gamcheon, Jagalchi, Gukje, Bujeon, Haedong Yonggungsa, Sky Capsule, Gwangalli, Haeundae, Huinnyeoul, Songdo Skywalk, Taejongdae |
| 예약 | 페이지 내 폼 (성명·이메일·WhatsApp·회사·도시·날짜·인원·기간) |
| **가격** | **페이지에 없음** → 산출물에 가격을 쓰지 마라 |

**`www.`를 빼지 마라.** apex(`sojournkorea.net`)는 `www`로 308 리다이렉트된다. 리다이렉트가 한 번 더 끼면 SNS 프리뷰 카드가 깨지거나 클릭 추적이 유실될 수 있다.

`/tour.html`, `/tour`, `/private-tour.html`은 전부 새 주소로 308 리다이렉트된다. 과거 링크는 살아있지만 **신규 산출물에는 정식 URL만 쓴다.**

## 1. 컬러 토큰

```
--blue        #1C3FE8   주 브랜드. 배경 또는 초대형 타이포
--blue-deep   #0B1F8C   그라데이션 하단, 그림자, 겹침
--ink         #0A0E1A   다크 배경, 본문 텍스트
--white       #FFFFFF   반전 배경, 텍스트
--coral       #FF4438   액센트 1 (부기 안경 색에서 추출)
--sand        #F5C24B   액센트 2 (부기 부리 색에서 추출)
--paper       #F1F0EC   오프화이트 배경 (콜라주용)
```

**사용 규칙 — 이걸 어기면 6장이 흩어져 보인다:**
- 카드 1장의 배경은 `blue` / `white` / `ink` 중 **정확히 하나**.
- 액센트(`coral` 또는 `sand`)는 **카드당 1종만**, 면적 15% 이하.
- 6장 세트에서 배경 리듬을 만들어라. 권장: `blue → white → blue → ink → white → blue`.
- 그라데이션은 `blue → blue-deep` 단 하나만 허용. 그 외 모든 그라데이션 금지.
- 보라/인디고 계열 금지. 이유: AI 생성물 클리셰이자 브랜드 블루와 충돌한다.

## 2. 타이포그래피

| 역할 | 폰트 | 크기(1080 기준) | 규칙 |
|------|------|----------------|------|
| Display | Anton (fallback: `Arial Black`, Impact) | XL 210 / L 152 / M 108 | line-height 0.86, letter-spacing -0.02em, **UPPERCASE** |
| Sub | Inter 700 | 36 | line-height 1.25 |
| Body | Inter 400 | 28 | line-height 1.45 |
| Label | Inter 600 | 22 | UPPERCASE, letter-spacing 0.14em |

**Display 카피 규칙 (레퍼런스의 핵심):**
- **1~3 단어**, 총 14자 이내. 문장이 아니라 **덩어리**여야 한다.
- 길면 줄여 쓰지 말고 **단어를 바꿔라**. 크기를 줄이는 순간 레퍼런스 느낌이 죽는다.
- 프레임 밖 블리드 허용 — 좌우 최대 -48px까지 잘려나가도 된다. 단어의 첫 글자는 절대 자르지 마라.
- 두 줄 이상이면 줄마다 다른 처리(솔리드 / 아웃라인 / 하이라이트 박스)를 줘서 층을 만들어라.

## 3. 레이아웃 아키타입

카드마다 자유롭게 짜지 말고 아래 6개 중에서 고른다. 이유: 6장이 한 세트로 읽히고, 검수가 기계적으로 가능해진다. CSS 클래스는 `assets/brand.css`에 정의되어 있다.

| 클래스 | 구성 | 적합한 역할 |
|--------|------|------------|
| `.lay-bleed` | 초대형 워드가 화면 밖으로 블리드 + 부기 오버랩 | 표지(HOOK) |
| `.lay-split` | 사선 컷으로 상하 2분할, 색 반전 | 문제 제기(PROBLEM) |
| `.lay-stack` | 좌측 정렬 3단 텍스트 스택 + 우측 부기 | 해법(SOLUTION) |
| `.lay-quote` | 화이트 박스 인용 + 콜라주 요소 | 증거·후기(PROOF) |
| `.lay-steps` | 번호 리스트 3~4행 | 코스 소개(ITINERARY) |
| `.lay-cta` | 하단 CTA 밴드 + 부기 풀샷 | 마무리(CTA) |

## 4. 그리드 & 세이프에어리어

- 캔버스 **1080 × 1080** 고정.
- 여백 72px. **세이프에어리어 = 사방 72px** — 로고·핸들·CTA·본문은 이 안에 있어야 한다.
- 인스타 피드 그리드 크롭을 고려해 **하단 100px에는 의미 있는 텍스트를 두지 마라.**
- 상단 락업 고정: 좌측 `SOJOURN KOREA` 워드마크, 우측 `@handle`. 6장 전부 동일 위치.

## 5. 부기(Boogi) 사용 규칙

부기는 장식이 아니라 **매 카드의 화자**다. 부산을 대신 말해주는 역할을 준다.

부기는 **부산광역시 저작물**이다. 우리가 마음대로 다룰 수 있는 소재가 아니다. 아래는 요약이며, **부기를 배치·편집·검수하기 전에 `references/boogie-usage.md`를 반드시 읽어라.** 공식 가이드북 2종에서 추출한 전체 규정이 거기 있다.

**라이선스 — 시작 전 해결**
공공누리 **제4유형** (출처표시 + 상업적 이용 금지 + 변형 금지). 상업적 이용과 100인 이상 배포는 **부산시 서면 승인 필수**이며 우리 캠페인은 둘 다에 해당한다. 이용료는 부산 소재 소상공인 무료지만 **무료가 승인을 대체하지 않는다.** 승인 전에는 내부 시안까지만.

**절대 금지 — 공식 규정**
- **좌우 반전 금지.** CSS `transform: scaleX(-1)`로 뒤집지 마라. 이유: 반전 시 스마트 글래스 우측 돌출 바를 따로 적용해야 한다는 규정이 있어, 단순 미러링은 그 자체로 규정 위반 형태가 된다.
- **비율 왜곡 금지.** 눈·입 간격과 크기를 기본형대로 유지한다. 한 축만 늘리지 마라.
- **색상 변경 금지.** 부리는 노랑, 안경은 빨강. 신발만 단색 변경 가능하고 형태 변형은 불가.
- **입을 벌린 형태로 변경 금지.** 말하는 연출은 말풍선으로 해라.
- **AI로 새 포즈·표정·의상을 생성하지 마라.** 이유: 2차적 저작물 작성이라 라이선스가 금지한다. 배경 제거와 업스케일만 허용된다.
- 규정 표정 8종·규정 의상 외 임의 제작 금지. 턴어라운드 이미지는 참고용이며 그래픽 소스로 쓸 수 없다.
- 주류·담배·정치·의료 소재와 병치 금지. 이유: 부산시 이용 약관의 명시적 제외 대상이다.

**필수**
- **누끼(투명 배경) PNG**만 쓴다 → `assets/boogie/boogie-cutout.png`. 원본 JPEG는 흰 배경이라 블루 카드에 흰 사각형이 남는다.
- 새 포즈가 필요하면 **공식 응용동작 카탈로그**에서 고른다. 여행·관광 동작(캐리어, 갈맷길, 서핑, 관광안내, 가족 사진, 비행기)이 이미 제공된다 — `references/boogie-usage.md` §5.
- **부기가 등장하는 카드마다 저작권 표기**를 캐릭터 옆 또는 아래에 넣는다 (`.char-credit` 클래스):
  `BOOGI ©2021. Busan Metropolitan City All Rights Reserved.`
- 6장 중 3~5장 등장, 01에는 반드시. 최소 높이 **360px**, 회전 ±8도 이내. 얼굴·안경을 가리지 마라.

## 5-1. 사진·이미지 규칙

레퍼런스 두 장 모두 화면의 절반이 이미지다. **타이포만으로 카드를 채우면 빈 공간이 미완성으로 읽힌다.**

**장소 이미지는 AI로 만들지 마라 (ADR-010).** 감천·자갈치·용궁사·광안대교는 실제 방문을 약속한 곳이라, 실물과 다른 이미지는 스타일 문제가 아니라 약속의 허위 표시다. 실사진 또는 라이선스 스톡만 쓴다.

| 슬롯 | 무엇 | AI |
|------|------|-----|
| `place` | 실제 방문 약속 장소 | **금지** |
| `concept` | 개념·소품·질감 (버스 내부, 시계, 손, 지도) | 허용 |

모든 이미지는 `assets/photos/manifest.json`에 등재한다. 등재 없이 쓰면 렌더러가 차단한다. `<img>`에 `data-photo`(매니페스트 키)와 `data-slot`을 반드시 붙인다.

**트리트먼트** — 서로 다른 날 다른 폰으로 찍은 사진도 한 색 체계로 묶는다:

| 클래스 | 효과 |
|--------|------|
| `.photo-mono` | 흑백 고대비. reference1의 콜라주 레지스터 |
| `.photo-duo` | 브랜드 블루 듀오톤 (luminosity 블렌드) |
| `.photo-frame` | coral 오프셋 솔리드 그림자. 소프트 섀도 금지 |
| `.photo-cut` | 투명 PNG 누끼, 프레임 없음 |

스톡·라이선스 이미지는 해당 카드에 `.photo-credit`이 필요하다. 자사 촬영분과 AI 개념 이미지는 매니페스트 기록으로 충분하다.

촬영해야 할 목록: `docs/SHOTLIST.md`

## 6. 영문 톤앤매너

사이트 톤은 "손을 잡고 함께 진행한다"는 신뢰형 동행자다. 마케팅 카피도 여기서 벗어나지 않는다.

| 축 | 방향 |
|----|------|
| 인칭 | **you** 중심. "we offer"보다 "you skip the guesswork" |
| 문장 | 짧게. 평균 12단어 이하. 카드 서브카피는 8단어 이하 |
| 태도 | 자신 있게, 과장 없이. 여행사가 아니라 **현지에 사는 사람**의 목소리 |
| 근거 | 숫자·고유명사를 넣어라. "beautiful beaches" ✗ / "Gwangalli, 8pm, bridge lights on" ○ |

**금지 표현 — 이유와 함께**
- `hidden gem`, `must-visit`, `breathtaking`, `nestled`, `vibrant`, `unforgettable journey`
  → 이유: 모든 여행 상품이 쓰는 무의미어라 차별점을 지운다.
- `Powered by AI`, 이모지 3개 이상 연속, 느낌표 2개 이상
  → 이유: 신뢰형 톤과 충돌한다.
- 확인되지 않은 가격·소요시간·운영시간
  → 이유: 투어는 실제 이행 약속이다. 틀리면 환불·분쟁 사유다.
- 한국어 혼용. 이유: 이번 캠페인은 영어 단독으로 확정됐다. 고유명사(Gwangalli, Gamcheon)는 영문 표기 사용.
