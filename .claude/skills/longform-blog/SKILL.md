# Longform Blog — 3,000자 영문 / 구글 SEO

자사 사이트(sojournkorea.net)에 게재하는 영문 롱폼. 목적은 조회수가 아니라 **`/private-tour` 랜딩으로 가는 링크주스와 예약 문의**다.

## 먼저 읽어라

1. `.claude/skills/sojourn-brand-system/SKILL.md` — 톤, 금지 표현, 채널 규격
2. `_workspace/01_brief.json` — 앵글, 페르소나, SEO 키워드, **facts 원장**
3. `output/blog.md` (있으면) — 재실행 시 기존 원고를 읽고 개선분만 반영

## 분량 기준

**3,000자 내외 (영문, 공백 포함) = 대략 480~550 단어.** 한국어 3,000자와 혼동하지 마라 — 영문 3,000자는 짧은 글이다. 이 분량에서는 주제를 넓게 펴면 전부 얕아지므로, **브리프의 앵글 하나만 깊게 판다.**

허용 오차 ±10% (2,700~3,300자). 완료 보고에 실제 글자 수를 적어라.

## 구조

```
H1  — primary 키워드를 자연스럽게 포함, 60자 이내
리드 — 2~3문장. 검색자가 가진 문제를 먼저 말한다. 회사 소개로 시작하지 마라.
H2  — 문제의 구체적 모습 (경쟁 대안이 왜 안 되는지)
H2  — 프라이빗 투어가 그걸 어떻게 바꾸는지
H2  — 실제 하루 (시간대별 3~4 스텝, 고유명사와 시각 포함)
H2  — 누구에게 맞고 누구에게 안 맞는지  ← 신뢰의 핵심. 생략하지 마라
H2  — FAQ 3문항
CTA — /private-tour 링크 1회
```

**"누구에게 안 맞는지" 섹션을 반드시 넣어라.** 이유: 사이트 톤이 신뢰형 동행자다. 모두에게 좋다고 말하는 글은 광고로 읽히고, 못 맞는 경우를 먼저 말하는 글은 상담으로 읽힌다.

## SEO 규칙

| 항목 | 규칙 |
|------|------|
| primary 키워드 | H1 1회 + 리드 1회 + 본문 2~3회. 그 이상은 스팸 신호 |
| secondary | H2에 자연스럽게 분산 |
| entities | 브리프의 고유명사를 최소 5개 본문에 등장시킨다. 구글이 주제를 판별하는 신호다 |
| 메타 디스크립션 | 155자 이내, 프론트매터에 |
| 내부 링크 | `/private-tour` 1회 필수. 관련 서비스 페이지 1~2회 |
| 이미지 alt | 카드뉴스 PNG를 본문에 쓸 경우 alt에 키워드가 아닌 **설명**을 넣어라 |
| FAQ | H3 질문 + 답변 2~3문장. JSON-LD FAQPage 스키마를 프론트매터에 함께 출력 |

**키워드를 억지로 반복하지 마라.** 구글은 2026년 기준 반복 밀도가 아니라 주제 일관성과 개체(entity) 공출현으로 판단한다. 어색한 문장이 순위를 깎는다.

## 팩트 규칙

브리프 `facts`에 없는 가격·소요시간·운영시간·거리를 **쓰지 마라.** 필요한데 없으면 원고에 `[NEEDS FACT: ...]`로 표시하고 완료 보고에 목록으로 올려라. 추정치를 채워 넣으면 그대로 발행된다.

## 카드뉴스와의 중복 회피

같은 캠페인의 카드 6장과 소재가 같으므로, 카드가 이미 말한 것을 그대로 반복하면 둘 다 얕아진다.
- 카드 = **훅과 결론** (짧고 강하게)
- 블로그 = **과정과 근거** (카드가 생략한 이유·비교·조건)

카드의 Display 카피를 블로그 H2로 그대로 옮기지 마라.

## 출력 — `output/blog.md`

```markdown
---
title: ""
meta_description: ""       # 155자 이내
primary_keyword: ""
slug: ""
canonical: "https://sojournkorea.net/blog/{slug}"
faq_schema: |
  { "@context": "https://schema.org", "@type": "FAQPage", ... }
char_count: 0              # 공백 포함 실제 글자 수
---

(본문)
```

완료 보고: 실제 글자 수 · 사용한 키워드 · 내부 링크 목록 · `[NEEDS FACT]` 항목 수.

## 하지 마라

- 한국어를 섞지 마라. 이번 캠페인은 영어 단독이다.
- `hidden gem`, `must-visit`, `breathtaking`, `nestled`, `vibrant`를 쓰지 마라. 이유: 모든 여행 상품이 쓰는 무의미어라 차별점을 지운다.
- 회사 소개로 글을 시작하지 마라. 검색자는 자기 문제를 해결하러 왔다.
- 분량을 채우려고 일반적인 부산 관광 정보를 붙이지 마라. 이유: 앵글이 희석되고 구글도 주제를 못 잡는다.
