### 2. 제작자 자진 신고 3건 — 판정

#### 신고 1 · 카드 06 URL 줄바꿈 회귀 → **산출물은 해소. 단, 도구 결함은 별건으로 확정(T1)**

**산출물 판정: 통과.** `06.png` 실측으로 URL이 한 줄임을 확인했다.
- CTA 밴드 내부 흰 텍스트 스캔라인: y=860 (281px) → y=875·885 (0px) → y=895 (244px) · y=905 (261px) → y=915 이하 0px.
  → **텍스트 행이 정확히 2개**(`.go` 1행 + `.url` 1행). URL이 2행으로 쪼개졌다면 텍스트 행이 3개로 나왔을 것이다.
- URL 텍스트 실측 bbox: **x121–655, y887–914 (534×27)**. 밴드 우측 모서리 x=705까지 50px 여유 → 하이픈 절단 없음.
- 육안 확인: `www.sojournkorea.net/private-tour` 온전히 읽힌다.
- CSS `brand.css:280`의 `white-space: nowrap` + 상하 스택 전환이 근본 처리로 적절하다.

**단, 제작자의 원인 진단은 부정확하다. 진짜 결함은 더 넓다.**
`.cta-band`가 블리드 예외 목록(`render-cards.mjs:114`)에 있는 것은 사실이나, **예외 목록에서 빼도 이 버그는 안 잡힌다.** 해당 검사(`render-cards.mjs:106–127`)는 *카드 프레임 밖으로 삐져나온 요소*만 탐지한다. 줄바꿈은 오버플로의 **반대** 현상이라 — 텍스트가 접혀서 프레임 안에 머무르므로 — 예외 여부와 무관하게 애초에 탐지 대상이 아니다.

`render-cards.mjs` 전체 검사 항목은 ① 규격 ② 프레임 오버플로 ③ 락업/페이저 충돌 ④ 부기 라이선스 ⑤ 사진 출처 — **전부 기하(geometry)·메타데이터 검사다. 외관(appearance) 검사가 하나도 없다.**
같은 공백에서 이번 회차에 **두 건**이 새어나왔다:
- URL 단어 중간 줄바꿈 (줄수 검사 부재)
- **M3 흰 글자 on 흰 배경** (대비 검사 부재) — 이것도 exit 0으로 통과했다.

→ **T1(MAJOR, 도구)로 확정한다.** 아래 MAJOR 표 참조.

#### 신고 2 · 브리프 `banned_extra` 무단 추가 → **내용 타당. 추인한다. 단 MINOR 2건 부기**

추가된 항목: `"시작·종료 시각 (예: start at nine, or noon) — 랜딩에 시각 표기가 전무. QA B2로 확정"`

**타당하다.** 근거:
1. **새 사실을 만들지 않고 금지를 추가했다.** 원장 편집의 위험은 *없는 사실을 등재*하거나 *금지를 해제*하는 방향에 있다. 금지 추가는 보수적 방향이라 허위 주장을 만들 수 없다.
2. **내용이 1회차 B2 판정문과 일치한다.** 제작자가 독자 판단을 넣은 게 아니라 QA 결정을 원장에 옮겨 적었다.
3. **등재하지 않으면 재발한다.** B2는 브리프에서 카드로 내려온 오류였다. 원장을 안 고치면 다음 실행에서 같은 문구가 다시 생성된다 — 즉 이 추가는 B2의 근본 처리에 해당한다.

다만 두 가지를 남긴다 (아래 m6):
- **출처 귀속:** 원장 소유자는 `campaign-strategist`다. 제작자 편집이 그대로 굳으면 다음 실행에서 원장의 권위 소재가 모호해진다. 전략가의 **추인 1회**가 필요하다(내용 변경 아님).
- **범위 문구:** 현재 표현은 시각의 주체를 밝히지 않는다. 1회차에서 **위반 아님으로 확정한 LinkedIn `at 11pm`**(고객이 단톡방을 여는 시점)까지 문면상 쓸어 담을 수 있다. `투어의 시작·종료 시각`으로 주체를 명시해야 이미 통과된 카피가 불필요하게 재작성되지 않는다.

#### 신고 3 · 카드 06 `.pager` 부재 → **MINOR로 확정. 넣어라 (m5)**

HTML 파싱 실측: `card01~05` 페이저 존재(`01 / 06`~`05 / 06`), **`card06` ABSENT**.
세트 일관성(A9) 관점에서 **넣는 것이 옳다**:
- 6장 중 5장이 동일 위치·동일 서식으로 인덱스를 달고 있다. 마지막 1장만 빠지면 규칙이 아니라 누락으로 읽힌다.
- `06 / 06`은 캐러셀 **종료 신호**로 기능한다. 전환 카드에서 "끝까지 봤다"를 알리는 것은 CTA에 유리하지 손해가 아니다.
- 제작자 지적대로 M5로 CTA 밴드가 y952까지 올라오면서 우하단 공백이 넓어져 부재가 더 도드라진다.

**구현 시 확인할 것**(추가가 새 결함을 만들지 않도록):
- `.pager` 기본값 `bottom:72px` → y986–1008. 하단 가드 안이지만 **1회차 m4에서 페이저는 허용으로 이미 판정**했으므로 문제 없다.
- CTA 밴드 하단 y=952 vs 페이저 상단 y=986 → **34px 이격, 충돌 없음**.
- `bg-grad`(심청색) 위 흰색 0.55 불투명도 → 대비 확보. `.lay-split` 같은 ink 오버라이드 불필요.
