# PRD: Sojourn Korea 부산 프라이빗 투어 마케팅

## 목표

부산 프라이빗 투어 랜딩(`https://www.sojournkorea.net/private-tour`)으로 가는 트래픽과 예약 문의를, 캠페인 1회분 콘텐츠 세트를 반복 생산해 만든다.

성공 기준은 콘텐츠 생산량이 아니라 **랜딩 유입과 문의 폼 제출**이다. 조회수가 올라도 문의가 안 늘면 앵글이 틀린 것이다.

## 사용자

**Sojourn Korea 마케팅 담당 1인.** 디자이너·카피라이터·영상 편집자를 따로 두지 않고 혼자 캠페인을 돌린다.

이 제약이 설계 전체를 규정한다:
- 사람이 매번 판단해야 하는 지점이 많으면 운영이 안 된다 → 브랜드 규칙을 문서와 코드로 고정한다
- 산출물 검수를 사람 눈에만 맡길 수 없다 → 기계가 잡을 수 있는 것은 렌더 단계에서 잡는다
- 한 번 발행하면 회수가 어렵다 → 팩트·링크·라이선스는 발행 전 게이트로 막는다

## 핵심 기능

1. **캠페인 브리프** — 소재 하나 → 페르소나·훅 앵글·카드 6장 스켈레톤·SEO 키워드·팩트 원장. 뒤의 모든 산출물이 여기서 파생된다.
2. **카드뉴스 6장** — 1080×1080 영문. HTML/CSS로 조판하고 Playwright로 PNG를 뽑는다.
3. **블로그 3,000자** — 자사 사이트 게재, 구글 SEO. 메타·FAQ 스키마·내부 링크 포함.
4. **SNS 3편** — Threads / LinkedIn / X. 같은 메시지를 채널 문법에 맞게 각각 다르게 쓴다.
5. **브랜드 QA** — 발행 전 교차 검수. 렌더 이미지를 실제로 열어 확인하고, 팩트를 원장과 대조하고, PASS/HOLD를 판정한다.
6. **인스타 릴스** — QA를 통과한 카드 6장을 9:16으로 재활용.

## MVP 제외 사항

- **자동 발행.** 각 채널 API 토큰·비즈니스 계정 연동이 선행되어야 하고, 승인 없이 나가는 발행 사고를 막는 장치도 따로 설계해야 한다. 파일 산출까지만 한다.
- **서울 코스.** 부산에 집중한다. 랜딩에 서울 3코스가 있지만 이번 캠페인 대상이 아니다.
- **한국어판.** 사이트가 전면 영문이라 랜딩 경험과 끊긴다. 영어 단독으로 간다.
- **가격 소구.** 랜딩에 가격 표기가 없어 대조할 원본이 없다. 공식 가격표가 나오기 전까지 전 산출물에서 다루지 않는다.
- **고객 후기 카드.** 검증된 후기가 없다. 지어내지 않고 팩트 카드로 대체한다.
- **네이버 블로그.** 구글 SEO 한 곳에 집중한다.

## 디자인

- **초대형 볼드 타이포가 주인공.** 헤드라인 길이가 곧 레이아웃이다.
- **컬러 2개 + 극단 대비.** 브랜드 블루 + 액센트 1종.
- **부산시 캐릭터 부기를 화자로.** 장식이 아니라 부산을 대신 말하는 역할. 단 **부산시 서면 승인 전까지 대외 발행 금지.**
