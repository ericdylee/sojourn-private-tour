# 촬영 리스트 — 부산 루트

투어 운영 중에 찍으면 되는 사진 목록. **AI로 대체할 수 없는 것들**이다 (ADR-010).

폰 카메라로 충분하다. 광고 사진처럼 찍을 필요 없다 — 카드에서 흑백 콜라주나 블루 듀오톤으로 처리되기 때문에 **구도와 순간**이 화질보다 중요하다.

## 촬영 원칙

| 원칙 | 이유 |
|------|------|
| **가로/세로 둘 다 찍어라** | 카드는 1:1, 릴스는 9:16이다. 한 방향만 있으면 잘라 쓸 여유가 없다 |
| **가장자리를 넉넉히 남겨라** | 1:1과 9:16으로 크롭할 때 주제가 잘린다. 피사체를 화면 가득 채우지 마라 |
| **가장 큰 해상도로 찍어라** | 축소는 되지만 확대는 안 된다 |
| **손님 얼굴이 나오면 동의를 받아라** | 초상권. 동의가 애매하면 뒷모습이나 손만 찍어라 |
| **같은 장소를 시간대별로** | 아침 빛과 해질녘은 다른 카드에 쓰인다 |
| **사람이 없는 컷도 하나씩** | 텍스트를 얹을 여백이 필요하다 |

## 우선순위 C — 디테일 컷 (콜라주용)

큰 풍경 사이를 메우는 작은 조각들. 콜라주 레이어로 쓰인다.

- 차 키 / 핸들 위의 손
- 지도나 일정표를 든 손
- 시장에서 건네받는 음식 접시
- 신발과 골목 계단
- 차창에 비친 바다
- 손님 뒷모습 (얼굴 없이) — 걷는 순간

## 촬영 후 처리

1. 원본을 `assets/photos/place/`에 넣는다 (파일명: `gamcheon-rooftops.jpg` 처럼 내용을 알 수 있게)
2. `assets/photos/manifest.json`의 `photos` 배열에 등재한다:

```json
{
  "file": "place/gamcheon-rooftops.jpg",
  "slot": "place",
  "subject": "Gamcheon Culture Village 계단식 지붕 부감",
  "ai_generated": false,
  "rights": "own",
  "shot_at": "2026-08-15",
  "note": "오전 10시, 흐림"
}
```

3. `manifest.json`의 `wanted` 배열에서 해당 항목을 지운다

**등재하지 않으면 렌더러가 차단한다.** 이건 실수를 막는 장치다 — 출처를 모르는 이미지가 발행물에 들어가는 것이 이 파이프라인에서 가장 비싼 사고다.

## 스톡으로 메꿀 때

사진이 없는 지점은 Unsplash 등 상업적 사용이 허용된 스톡을 쓴다.

- `rights`를 `"unsplash"` 또는 `"licensed:<출처>"`로 기록한다
- 해당 카드에 `.photo-credit` 요소를 넣어야 한다. **넣지 않으면 렌더러가 차단한다**
- 스톡은 임시 방편이다. 실사진이 확보되면 교체한다 — 경쟁사와 같은 사진을 쓰는 한 차별점이 없다
